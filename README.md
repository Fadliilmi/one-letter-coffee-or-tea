One letter, B for tea: the truest answer in the coffee-against-tea argument, written by a program that answers with a single letter and nothing else.

## Run it

```sh
node main.ts
```

It writes exactly one byte, `B`, to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set for a local check). No network, no dependencies — Node 22 runs it as-is.
